# REQ-0036 — Git pull в скрипте запуска

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: В работе.
- Источник: скрипт запуска также должен делать git pull.
- Связи: REQ-0025, REQ-0035.

## Требование и границы

Перед сборкой скрипт scripts/build-and-run.sh обновляет текущую ветку командой
`git pull --ff-only` из каталога проекта. Используется настроенный upstream,
ветка автоматически не переключается. Ошибка Git останавливает обновление
до сборки и запуска; принудительный сброс, stash и merge-коммиты не выполняются.
Обновить справку и README, опубликовать d/raci.

## Критерии приёмки

- Из любого cwd pull выполняется в каталоге проекта до сборки образа.
- При неуспехе pull Docker не запускается, скрипт возвращает ошибку.
- После успешного pull сохраняется прежняя сборка и запуск.
- --help не обновляет Git и не вызывает Docker.
