# REQ-0037 — Доступ администратора и коммит в футере

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: сообщить текущие логин и пароль; вывести короткий хеш коммита внизу в футере.
- Связи: REQ-0007, REQ-0025.

## Требование и границы

Прочитать только логин администратора из доступной локальной SQLite.
Пароль хранится как scrypt-хеш, восстановление открытого значения невозможно;
не менять учётные данные без запроса. Другой хост пользователя недоступен.
Добавить общий футер HTML-страниц с коротким хешем версии исходников.
Скрипт передаёт коммит после git pull в образ через build arg APP_COMMIT;
Compose также принимает этот build arg из окружения. Локально читать Git один раз
при старте; без метаданных показывать «неизвестен». PDF не изменять.

## Критерии приёмки

- Ответ различает проверенный логин и неизвестный открытый пароль.
- Футер есть на форме, в админке и HTML-отчётах; вывод безопасно экранируется.
- Сборка скриптом фиксирует короткий коммит в образе без передачи .git.
- Проверены обычный запуск и Docker; изменения опубликованы в d/raci.

## Результат и проверка

Локальная SQLite открыта только на чтение: логин admin. Пароль не извлекался
и не менялся; сохраняется scrypt-хеш. Другая машина пользователя не проверялась.
Добавлены src/version.py и общий footer.html, подключённый на форме, в админке
и обоих HTML-отчётах. Получение версии один раз при старте: APP_COMMIT, затем Git;
при отсутствии/некорректном значении — «неизвестен». Хеш ограничен hex, 7 символов.
Dockerfile принимает ARG APP_COMMIT и сохраняет ENV; скрипт определяет хеш после
pull и передаёт в docker build, Compose принимает build arg из окружения.
.git в образ не включается, PDF не меняется. Обновлён README.

Прошли 28 тестов админки и HTML, bash -n, проверки версии из Git/env,
отсутствия Git, неверного ввода, футера на 4 страницах. Скриптом успешно собран и запущен Docker: APP_COMMIT=9f57667,
футер реального HTTP-ответа содержит 9f57667. Venv перезапущен.
ARG/ENV перенесены после установки зависимостей, чтобы смена хеша не сбрасывала
кеш pip. Прямую Compose-сборку документировали с явным APP_COMMIT.
