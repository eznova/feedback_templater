# REQ-0031 — Отдельный SSH-ключ e_znova

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: сгенерировать отдельный ключ в moc для e_znova; пользователь добавит публичную часть в профиль GitHub.
- Связи: REQ-0030.

## Требование и границы

Создать отдельную пару Ed25519 в /root/moc/.ssh/ с комментарием e_znova@mail.ru.
Показать пользователю публичный ключ. Закрытая часть остаётся вне репозитория,
доступна только владельцу. Настроить использование ключа только для этого репозитория.
Публикация ветки требует добавления публичной части пользователем в GitHub.

## Критерии приёмки

- Пара ключей создана без перезаписи существующих файлов.
- Каталог имеет права 700, приватный ключ — 600.
- Публичный ключ доступен для добавления в GitHub; секреты не включены в Git.

## Результат и проверка

Созданы /root/moc/.ssh/id_ed25519_e_znova и файл .pub, Ed25519,
комментарий e_znova@mail.ru, без парольной фразы для использования Git.
Права проверены stat: каталог 700, приватный ключ 600, публичный 644.
Отпечаток проверен ssh-keygen -lf; публичная часть показана пользователю.
В локальном .git/config задан core.sshCommand с этим ключом и IdentitiesOnly=yes.
Ключи находятся вне репозитория и не коммитятся.
Ожидается добавление публичного ключа в профиль GitHub, затем продолжение REQ-0030.
