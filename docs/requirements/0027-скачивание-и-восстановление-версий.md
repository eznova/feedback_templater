# REQ-0027 — Скачать и восстановить доступную версию БД

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: возможность скачать/восстановить любую доступную версию БД.
  Уточнение: восстанавливать только тексты RACI.
- Связи: REQ-0021, REQ-0022, REQ-0024.

## Требование и границы

В истории backup у каждой версии добавить скачивание полного файла SQLite
и восстановление 12 текстов RACI с подтверждением. Логин, пароль и сессия
текущего администратора сохраняются. Восстановление создаёт новую ревизию,
предварительно сохраняя текущую БД. История остаётся в пределах 20 копий.

Выбранную копию прочитать до создания backup: восстановление самой старой
версии должно работать, даже если очистка затем удалит её файл.
Поддерживать прежние совместимые схемы 0 и 1, проверять целостность и набор ключей.
Для локальных версий не применять ограничение 32 МиБ загрузки из браузера.
Отсутствующие/удалённые копии, сторонние пути и символические ссылки отклонять.
Все операции доступны только после входа, POST защищён CSRF, ответы не кэшируются.

## Критерии приёмки

- У каждой доступной копии есть кнопки скачивания и восстановления текстов.
- Скачивается именно выбранный файл, а не текущая БД; скачивание не меняет ревизию.
- Восстанавливаются все тексты выбранной версии, сохраняются администратор и сессия.
- Backup перед восстановлением содержит прежнее текущее состояние, ревизия увеличивается.
- Восстановление самой старой из 20 копий проходит, лимит истории соблюдён.
- Неверная копия или ошибка backup не меняет данные; обход путей и доступ без входа запрещены.

## Результат и проверка

В истории версий добавлены кнопки скачивания и POST-восстановления текстов
с подтверждением. Новые маршруты `/admin/backups/<filename>/download` и
`/admin/backups/<filename>/restore` защищены входом, восстановление — CSRF;
ответы имеют no-store. Разрешены только доступные обычные файлы из backups/,
символические ссылки и обход путей отклоняются.

Выбранный снимок читается до создания нового backup; общая проверка текстов
вынесена в `read_database_texts`. Восстановление меняет только texts через
database_change, сохраняет администратора и сессию, увеличивает ревизию.
Повреждённые/недоступные версии дают ошибку без замены данных.

Все 24 теста админки/БД прошли: скачивание каждой доступной копии без записи,
восстановление выбранных текстов с предварительным backup, ревизией и сохранением
администратора, самая старая копия при лимите 20, схема 0, неверные файлы,
авторизация/CSRF/обход путей/символические ссылки и отказ при ошибке backup.
Наличие обеих кнопок в HTML отдельно проверено повторным целевым тестом.
Docker-сервис пересобран и перезапущен через scripts/build-and-run.sh;
сервер venv также обновлён. README и контекст обновлены. `git diff --check` прошёл.
Реальное восстановление рабочей базы не выполнялось; сценарии восстановления
проверены на изолированных временных SQLite. Браузерное подтверждение вручную не проверялось.
