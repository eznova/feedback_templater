# REQ-0013 — Перенос длинных блоков PDF

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: блоки текста должны переноситься на следующую страницу при
  превышении объёма одной страницы.
- Связи: заменяет ограничения одной страницы, уменьшение шрифта и ошибку
  переполнения из REQ-0008 и REQ-0011. Сохраняет оформление REQ-0009–0010.

## Требование и границы

Разбивать длинный текст по строкам на дополнительные страницы без обрезки
и уменьшения основного шрифта (11 pt). Перенос определяется реальной высотой
текста с учётом ширины и переносов, а не фиксированным числом символов.
Убрать ограничение 20 000 символов на поле.

Вводные разделы начинаются вместе на первой странице; если не помещаются,
продолжаются дальше, оставаясь без фона. Каждый процесс начинается с новой
страницы, а его блоки при необходимости продолжаются на следующих.
На продолжениях повторять общий заголовок, адресата (если выбран), название
раздела и подпись блока с пометкой «продолжение»; цвет блока сохранять.
Короткий документ по-прежнему содержит шесть страниц.

## Критерии приёмки

- Длинные вводные тексты, «Как было» и целевые тексты дают PDF вместо ошибки.
- Весь текст, включая начало и конец, присутствует один раз и в исходном порядке.
- У продолжений сохранены подписи и фон; текст не выходит за поля A4.
- Поддерживается поле длиннее прежнего ограничения 20 000 символов.
- Короткие и пустые тексты сохраняют шесть страниц; варианты адресата работают.

## Результат и проверка

В `raci_pdf.py` добавлен `PdfLayout`, который разбивает абзацы через
`Paragraph.split` по доступной высоте страницы. Продолжения сохраняют фон,
повторяют заголовки и подпись блока. Размер текста — 11 pt; ограничения
20 000 символов и ошибки переполнения удалены. README обновлён.

Все десять тестов панели и PDF прошли. Для каждого из четырёх типов поля
(два вводных, «Как было», целевая картина) проверены более 20 000 символов:
700 уникальных маркеров извлечены из PDF ровно один раз в исходном порядке.
Через `pdftotext -bbox` проверены вертикальные границы текста на всех страницах.
Короткие и пустые документы сохраняют шесть страниц, варианты адресата работают.
HTTP-обработчик проверен с 1500 строками: 200 и PDF с дополнительными страницами.
Визуально проверена третья страница `/tmp/raci-pagination.pdf`: сиреневый блок
продолжается с подписью, общим заголовком и адресатом. `git diff --check` прошёл.
