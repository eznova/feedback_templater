# REQ-0015 — Тест переноса 100 000 символов

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «Добавь тест, который заполнит блоки текстом на 100 тыс символов
  для проверки переноса».
- Связи: проверяет REQ-0013, использует Inter по REQ-0014.

## Требование и границы

Добавить автоматический тест генератора PDF: одновременно заполнить все
12 текстовых полей RACI ровно 100 000 символов каждое (всего 1 200 000).
Использовать кириллический текст и уникальные маркеры, проверить переносы
и полноту содержимого. Тестовые данные не записывать в рабочую SQLite.

## Критерии приёмки

- Тест проверяет длину каждого из 12 полей и успешно формирует PDF.
- Каждый блок занимает несколько страниц.
- Извлечённый текст после удаления повторяющихся заголовков и нормализации
  пробелов совпадает с исходным, без пропусков, повторов и перестановок.
- Тест можно запустить отдельно; зависимость от Poppler описана.

## Результат и проверка

Добавлен `tests/test_pdf_stress.py` с тестом
`PdfStressTests.test_all_blocks_with_100_000_characters`.
В каждом поле 1000 строк по 100 символов, с уникальными маркерами поля и строки.
Все 12 полей заполнены одновременно, затем PDF разобран через `pdftotext`.
Проверяется перенос каждого поля на несколько страниц и полное совпадение
извлечённого текста с исходным после удаления служебных заголовков и пробелов.
База данных не используется, файл PDF на диск не записывается.

Отдельный запуск успешно завершён: **567 страниц, 1 200 000 исходных символов,
59,284 секунды, OK**. README дополнен командой запуска и требованием Poppler.
`git diff --check` прошёл. Код генератора и работающий сервер не изменялись.
