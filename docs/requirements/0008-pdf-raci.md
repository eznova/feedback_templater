## Требование и границы

Кнопка формы RACI скачивает PDF из текущего ввода: семь страниц A4 в порядке
семи разделов. Каждая страница содержит заголовок «Как это повлияет на HR-процессы
в [название подразделения]», необязательную сиреневую плашку адресата и название раздела.
У пяти разделов процессов — серый блок «Как было» и сиреневый блок
«Как будет в целевой картине» с округлёнными углами, как на скриншоте.
Предположение для первых двух пунктов: один сиреневый блок с текстом,
без выдуманных полей «Как было». Пустые поля сохраняют место соответствующего блока.

Два варианта плашки: «для руководителя отдела» / «для руководителя сектора»;
значение «Не отображать» полностью убирает плашку. Кириллица, переносы строк
и введённый текст сохраняются. PDF не меняет исходные тексты SQLite.
Чекбоксы остаются без логики отключения, согласно предыдущему требованию.
Форма встреч продолжает выдавать прежний HTML-отчёт.

Чтобы не терять текст и сохранять ровно семь страниц, при переполнении размер
шрифта уменьшается до читаемого минимума; если текст всё ещё не помещается,
показать ошибку с названием раздела и сохранить ввод вместо обрезки текста.

## Критерии приёмки

- POST формы скачивает PDF с семью страницами A4 и кириллическим текстом.
- На каждой странице ровно один раздел, в заданном порядке.
- Подразделение и адресат берутся из формы; скрытая плашка отсутствует.
- Пять процессных страниц имеют оба блока с подписями и заданными фонами.
- Переносы и специальные символы отображаются как текст; длинный текст
  не выходит за границы страницы и не теряется молча.
- Ошибки генерации не сбрасывают введённые значения.
- Сформирован пример PDF и визуально проверена процессная страница.

## Результат и проверка

Добавлен `raci_pdf.py` на ReportLab, встроены шрифты Liberation Sans с лицензией
в `assets/fonts/`. Генерация `POST /raci_generate` возвращает PDF-вложение `raci.pdf`;
при неверном вводе или переполнении — JSON с ошибкой (422).
Форма отправляется через fetch, показывает ошибку без сброса ввода и скачивает PDF.
README дополнен описанием, команда PyInstaller учитывает каталог assets.

Восемь тестов панели и PDF прошли: семь страниц, встроенные шрифты, порядок
разделов, извлечение кириллицы и специальных символов, три варианта адресата,
пустые блоки и переполнение. Проверен HTTP-обработчик через клиент Flask
(PDF 200, ошибки 422), GET / и сохранена генерация HTML встреч.
Тестовый PDF `/tmp/raci-example.pdf` отрисован через Poppler, третья страница
визуально сопоставлена со скриншотом. Проверка браузерного скачивания вручную
не проводилась. `git diff --check` проходит.
