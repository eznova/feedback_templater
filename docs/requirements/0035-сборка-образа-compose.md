# REQ-0035 — Согласованная сборка и порты Compose

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: В работе.
- Источник: логи хоста показывают app на 5000 при публикации 5081:18500; порты не согласованы.
- Связи: REQ-0025, REQ-0029, REQ-0034.

## Требование и границы

Устранить использование старого образа при стандартной команде Compose --build.
В d/raci исходники src.app слушают 18500, Dockerfile EXPOSE 18500 и публикация
5081:18500 уже согласованы. В текущем Compose отсутствует build, поэтому --build
не пересобирает образ image: feedback_templater, сохранившийся от main (5000).
Добавить build: . и описать обновление. Логи другого хоста доступны только
в сообщении пользователя; на нём команды не выполняются.

## Критерии приёмки

- docker compose up -d --build пересобирает актуальный Dockerfile для d/raci.
- Контейнер запускает python -m src.app, внутренний порт 18500, хост 5081.
- Главная страница и локальный CSS доступны на 5081; instance сохраняется.
- Изменения опубликованы в d/raci, инструкция обновления дана пользователю.

## Результат и проверка

В docker-compose.yml добавлен build: ., README содержит команду обновления
и объяснение старого образа main. docker compose up -d --build --force-recreate
feedback_templater действительно выполнил сборку и пересоздал контейнер.
Compose config прошёл; inspect подтвердил CMD python -m src.app,
18500/tcp -> 5081 (IPv4/IPv6), прежний bind instance:/app/instance.
GET главной и локального CSS через 5081 — HTTP 200.
Python-код не менялся, повторные тесты приложения не требовались.
Изменения подготовлены к публикации в d/raci. На хосте пользователя
действия не выполнялись — ему требуется обновить ветку и пересобрать образ.
