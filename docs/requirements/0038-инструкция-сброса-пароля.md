# REQ-0038 — Инструкция сброса пароля

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: как сбросить пароль?
- Связи: REQ-0007, REQ-0037.

## Требование и границы

Дать команду смены пароля администратора в работающем контейнере d/raci.
Самостоятельно пароль не менять.

## Критерии приёмки

- Команда для Compose и указание интерактивного ввода с подтверждением.
- Указана минимальная длина пароля; перезапуск не требуется.

## Результат и проверка

По src/admin.py проверена команда:

```bash
cd ~/feedback_templater
docker-compose exec feedback_templater python -m flask --app src.app set-admin --username admin
```

Команда запрашивает новый пароль дважды скрытым вводом, минимум 12 символов.
После сохранения создаётся backup, отзываются прежние сессии,
сбрасывается блокировка входа. Перезапуск контейнера не нужен.
Пароль и база в этой задаче не менялись, команду сброса не запускали.
