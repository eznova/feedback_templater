# REQ-0034 — Работа d/raci без интернета

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: В работе.
- Источник: проверить наличие локального CSS в d/raci и добавить его; сайт должен работать без доступа к интернету.
- Связи: REQ-0033, REQ-0014.

## Требование и границы

Заменить загрузку Bootstrap с CDN на локальный файл в ветке d/raci,
включая главную форму и панель администратора. Поставлять CSS с приложением
и Docker-образом вместе с лицензией. Проверить отсутствие внешних ресурсов,
необходимых браузеру для работы форм и отчётов. Шрифты Inter уже локальные.
Предположение: автономность относится к работе собранного приложения;
первичная установка зависимостей и сборка образа могут требовать интернет.

## Критерии приёмки

- Форма и админка подключают локальный Bootstrap 5.3.2 без CDN.
- CSS и шрифты доступны через HTTP с самого приложения.
- В браузерных ресурсах нет внешних зависимостей; CSS-иконки встроены в файл.
- Изменения опубликованы в d/raci; рабочий сервис обновлён.

## Результат и проверка

В src/assets/ добавлены bootstrap.min.css 5.3.2 и bootstrap-LICENSE.txt
из проверенной локальной копии main. Главная форма и admin_base.html
подключают файл через url_for(static). README обновлён.

Прошли 28 тестов админки и HTML-отчёта. Flask test_client подтвердил HTTP 200
формы, входа, CSS и обоих Inter, отсутствие внешних ресурсов в шаблонах,
внешних url() и @import в CSS (иконки встроены data URI).
Docker пересобран и запущен scripts/build-and-run.sh. В одноразовом контейнере
с --network none успешно проверены формы, CSS, шрифты, HTML/PDF RACI и встреча.
Рабочий каталог данных к изолированной проверке не подключался.
Venv перезапущен. CSS на портах 5081 и 18500 вернул HTTP 200.
Остаётся публикация в origin/d/raci. Браузерная визуальная проверка не выполнялась.
