# REQ-0011 — Оба вводных раздела на первой странице

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «оба вводных раздела должны быть на 1 странице».
- Связи: REQ-0008, REQ-0009, REQ-0010. Заменяет правило отдельных страниц
  для первых двух пунктов; сохраняет отсутствие цветной подложки.

## Требование и границы

Уточнение REQ-0013: при длинных вводных текстах допускаются страницы продолжения;
уменьшение шрифта и отказ при переполнении заменены переносом. Для коротких текстов
сохраняется совместная первая страница и шесть страниц документа.

На первой странице PDF последовательно разместить «О матрице RACI» и
«Предпосылки внедрения», с одним общим заголовком и плашкой адресата.
Пять HR-процессов оставить на отдельных страницах. Итого шесть страниц.
При переполнении первой страницы уменьшать шрифт обоих вводных текстов;
если они не помещаются при 7 pt — возвращать ошибку без обрезки и потери ввода.

## Критерии приёмки

- PDF содержит шесть страниц даже при пустых текстах.
- Первая содержит оба вводных заголовка и текста в порядке формы, без подложек.
- Страницы 2–6 соответствуют пяти процессам с прежними цветными блоками.
- Оба вводных текста учитываются совместно при проверке переполнения.

сохранены. Обновлены README и пять тестов PDF: шесть страниц, оба вводных текста
