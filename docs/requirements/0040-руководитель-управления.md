# REQ-0040 — Адресат «Руководитель управления»

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: добавить в выпадающий список руководителя управления.
- Связи: REQ-0006, REQ-0008, REQ-0028.

## Требование и границы

Добавить в селект «Для кого» формы RACI вариант «Для руководителя управления».
Выбранный адресат отображается на плашке HTML-отчёта и PDF по общим правилам.
Значение сохраняется при ошибке валидации формы, вариант по умолчанию прежний.

## Критерии приёмки

- В селекте присутствует новый адресат с ключом directorate-head.
- Генерация HTML/PDF принимает его и выводит «для руководителя управления».
- При ошибке формы выбор сохраняется.

## Результат и проверка

В src/templates/raci_form.html добавлен пункт «Для руководителя управления»
с ключом directorate-head; src/raci_pdf.py содержит подпись нового адресата.
HTML и PDF используют общую проверку и подпись.
Прошли 13 тестов PDF/HTML; существующая проверка PDF перебирает все AUDIENCES,
включая новый вариант. Дополнительно через Flask test_client проверены наличие
пункта в форме, плашка HTML и сохранение выбора при ошибке 422.
Изменения публикуются в ветке d/raci.
