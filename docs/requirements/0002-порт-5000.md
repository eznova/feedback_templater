# REQ-0002 — Использовать порт 5000

- Дата: 2026-10-22 (Europe/Moscow).
- Статус: Зафиксировано.
- Источник: уточнение от 2026-10-23 — «исправь в 002 требовании порт обратно на 5000».
- Связи: уточняет REQ-0001.

## Требование и границы

Заменить порт приложения с 18500 на 5000 в коде, описании запуска и Dockerfile;
перезапустить работающий экземпляр в venv на новом порту.

## Критерии приёмки

- `app.py` задаёт `port=5000`, Dockerfile содержит `EXPOSE 5000`.
- README указывает `http://127.0.0.1:5000/`.
- Предыдущий экземпляр остановлен, новый отвечает HTTP 200 на порту 5000.

## Результат и проверка

Требование исправлено на порт 5000 по запросу пользователя.
Код, Dockerfile и работающий сервер в рамках правки документа не изменялись:
фактический порт остаётся 18500. Новые критерии приёмки пока не проверены.
Ожидаемая команда после реализации:

```bash
.venv/bin/python -m flask --app app run --host 0.0.0.0 --port 5000
```

`EXPOSE` описывает порт, но сам не публикует его на хосте.
