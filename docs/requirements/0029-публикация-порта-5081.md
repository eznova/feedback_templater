# REQ-0029 — Публикация сервиса на порту 5081

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: контейнер должен публиковать сервис на порту 5081; уточнение отменяет запрошенный ранее в прерванном ходе порт 8051.
- Связи: REQ-0025, REQ-0026.

## Требование и границы

В docker-compose.yml публиковать TCP-порт 5081 хоста на внутренний порт 18500
сервиса. Обновить документацию и применить конфигурацию к работающему контейнеру.

## Критерии приёмки

- Compose содержит публикацию `5081:18500`.
- После запуска главная страница доступна по http://127.0.0.1:5081/.
- Сохраняются подключённый каталог instance и сеть moc.

## Результат и проверка

В docker-compose.yml добавлено ports: ["5081:18500"], README обновлён.
Конфигурация прошла docker compose config --quiet; контейнер пересоздан через
docker compose up -d --force-recreate feedback_templater.
GET http://127.0.0.1:5081/ вернул HTTP 200; compose port показал 0.0.0.0:5081.
Через inspect подтверждены прежний bind instance:/app/instance и сеть moc.
Код приложения не менялся, пересборка образа и тесты Python не требовались.
