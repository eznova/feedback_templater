# REQ-0005 — Выбор шаблона

- Дата: 2026-10-22 (Europe/Moscow).
- Статус: Выполнено.
- Источник: заменить заголовок «Заполните данные встречи» на «Выберите шаблон»;
  добавить под ним select «Встречи» / «Матрица RACI». Для встреч показывать
  текущую форму; требования к форме RACI будут следующим запросом.
- Связи: расширяет REQ-0000 в части входной страницы.

## Требование и границы

Добавить переключение шаблона на главной странице без перезагрузки.
Предположение: по умолчанию выбран пункт «Встречи». При выборе RACI текущая
форма скрывается; вместо неё отображается сообщение о том, что форма пока
недоступна. Состав полей и генерация RACI в это требование не входят.

## Критерии приёмки

- Заголовок страницы — «Выберите шаблон», под ним select с двумя пунктами:
  «Встречи» и «Матрица RACI».
- По умолчанию видна существующая форма встреч с прежними полями и отправкой.
- При выборе RACI форма встреч и её кнопка отправки скрыты.
- Возврат к «Встречи» показывает форму и сохраняет введённые данные.

## Результат и проверка

Изменён `templates/form.html`: заголовок, доступный по имени select,
форма встреч по умолчанию и сообщение для RACI. Обработчик `change`
переключает атрибут `hidden`, не пересоздавая форму и не сбрасывая значения.
При загрузке состояние синхронизируется с выбранным пунктом.

Через тестовый клиент Flask проверены HTTP 200 для `GET /`, структура селекта,
исходная видимость формы и скрытое сообщение RACI, сохранение всех восьми полей,
а также `POST /ft_generate` с проверкой ФИО и форматирования даты в результате.
