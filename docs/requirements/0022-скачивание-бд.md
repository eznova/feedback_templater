# REQ-0022 — Скачивание текущей SQLite из админки

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: дать возможность скачать текущее состояние БД из UI.
  Почтовая отправка из первоначального запроса отменена пользователем.
- Связи: REQ-0021.

## Требование и границы

В админке добавить скачивание согласованного текущего снимка SQLite: тексты,
учётная запись, метаданные и версия схемы. Доступ только после входа, без кэширования.
Скачивание не меняет БД, ревизию и локальные резервные копии.

## Критерии приёмки

- Без входа скачать базу нельзя; скачанный файл целостен и содержит текущее состояние.
- Есть кнопка скачивания в админке; ответ — SQLite-вложение с версией в имени.
- Скачанный файл содержит актуальные тексты, администратора, ревизию и версию схемы.
- Скачивание не увеличивает ревизию, не создаёт backup и не кэшируется.

## Результат и проверка

Добавлены `database.export_database` и защищённый GET `/admin/download`.
SQLite Backup API создаёт согласованный снимок в памяти; имя вложения содержит
схему и ревизию именно этого снимка. Ответ имеет `Cache-Control: no-store`.
В панели добавлена кнопка «Скачать текущую БД», README дополнен описанием.
Почтовая отправка и SMTP-конфигурация не добавлялись после отмены пользователем.

14 тестов админки/БД прошли, включая запрет скачивания без входа, содержимое
и целостность файла, версию/ревизию в имени, сохранность текущей ревизии и backup,
совместимость скачанного файла с импортом и включение зафиксированных данных WAL.
Браузерное скачивание вручную не проверялось. `git diff --check` прошёл.
