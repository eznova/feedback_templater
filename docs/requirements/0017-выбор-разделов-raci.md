# REQ-0017 — Включение разделов RACI в PDF

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: чекбокс в строке названия каждого блока («О матрице», «Предпосылки»,
  «Подбор» и т. д.), изначально включённый; снятие исключает блок из документа.
- Связи: заменяет чекбоксы отдельных полей из REQ-0006; расширяет REQ-0013.

## Требование и границы

Семь разделов получают по одному чекбоксу в строке заголовка, все включены
по умолчанию. У процессов чекбокс управляет сразу полями «Как было» и целевой
картины. Прежние 12 чекбоксов возле textarea удаляются. Ввод сохраняется при
переключении: текстовые поля не очищаются. SQLite не изменяется.

PDF содержит только отмеченные разделы в прежнем порядке. Оставшиеся вводные
разделы располагаются вместе; если оба исключены, вводной страницы нет.
У исключённых процессов нет страниц и продолжений. Если всё выключено —
показать ошибку «Выберите хотя бы один раздел» без сброса формы.

## Критерии приёмки

- В форме семь включённых чекбоксов в заголовках.
- Каждый раздел можно независимо исключить: его заголовки и текст отсутствуют в PDF.
- Отсутствуют пустые страницы исключённых разделов.
- Выбранный процесс сохраняет оба поля и переносы длинного текста.
- Все включены — прежняя структура, все выключены — понятная ошибка.

## Результат и проверка

В `templates/raci_form.html` добавлен макрос заголовка с включённым чекбоксом;
удалены прежние чекбоксы полей. Форма передаёт `include_<ключ>=1` для отмеченных
разделов. В `app.py` выбор передаётся генератору; `build_raci_pdf` исключает
невыбранные разделы до компоновки. Пустой выбор даёт JSON-ошибку 422.
Прямой вызов генератора без аргумента `included_sections` сохраняет все разделы
для совместимости существующих тестов. README и контекст обновлены.

Девять тестов PDF и четыре теста панели прошли. Проверены независимое исключение
каждого из семи разделов, одиночный вводный/процессный раздел, отсутствие вводной
страницы, оба вводных вместе, пустой выбор, сохранение обоих полей процесса,
исключение длинных текстов без лишних страниц и прежние переносы.
Разбором HTML подтверждены семь отмеченных чекбоксов внутри заголовков;
через Flask-клиент проверены GET / (200), POST с одним разделом (PDF 200)
и пустым выбором (422). `git diff --check` прошёл.
Браузерное переключение вручную не проверялось; нагрузочный тест на 1,2 млн
символов повторно не запускался.
