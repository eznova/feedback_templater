# REQ-0007 — Панель администратора и SQLite

- Дата: 2026-10-22 (Europe/Moscow).
- Статус: Выполнено.
- Источник: добавить панель под логином и паролем, редактирование текстов,
  хранение актуального состояния в SQLite. Уточнение: начальные тексты полей RACI.
- Связи: REQ-0006; начальные значения RACI теперь управляются через базу.

## Требование и границы

Панель `/admin` доступна только после входа. Администратор редактирует начальные
значения всех 12 textarea RACI, включая пустые «Как было». Сохранение — одной
операцией в SQLite; новые открытия публичной формы используют сохранённые значения.
Пользовательский ввод в публичной форме не изменяет общие начальные тексты.
Существующие данные в открытых вкладках не перезаписываются автоматически.

SQLite хранит тексты и учётную запись администратора (хеш пароля).
Создание/смена учётной записи — локальной CLI-командой, без публичной регистрации.
Предусмотреть выход, CSRF-защиту операций панели и сохранение сессий после перезапуска.
База и ключ сессий — в игнорируемом каталоге `instance/`.

## Критерии приёмки

- Без входа редактирование недоступно; неверный пароль не даёт доступ.
- Корректный вход открывает редактор 12 начальных текстов.
- Изменение, включая очистку, отображается в публичной форме и сохраняется
  при повторной инициализации приложения с той же базой.
- Пароль не хранится открытым текстом; неверный CSRF-токен блокирует запись.
- Выход закрывает доступ; генерация встреч работает как прежде.
- Описаны путь базы, настройка учётной записи и резервное копирование.

## Результат и проверка

Добавлен `admin.py`: инициализация SQLite без перезаписи существующих текстов,
вход, выход, редактор, CLI `set-admin`. Пароли — scrypt-хеши, формы панели
защищены CSRF; после пяти неверных входов блокировка на пять минут.
Смена учётной записи отзывает старые сессии. Ключ сессии сохраняется локально,
ответы панели имеют `Cache-Control: no-store`.

Добавлены шаблоны панели; публичная RACI получает значения из базы через `app.py`.
В `docker-compose.yml` удалён общий пример `SECRET_KEY`, чтобы использовать
автоматически созданный ключ в сохраняемом `instance/`. README содержит настройку
учётной записи и резервное копирование. Создан администратор `admin` со случайным
паролем; сам пароль в документацию и исходники не записан.

В `tests/test_admin.py` проверены запрет доступа, неверный и корректный вход,
CSRF, неполное сохранение, выход, блокировка перебора, смена пароля, сохранение
и очистка текстов, экранирование HTML, сохранность SQLite и сессии после повторной
инициализации. Четыре теста проходят на отдельной временной базе.
Отдельно проверены GET /, GET /admin/login, перенаправление /admin и генерация
встречи через POST /ft_generate. Интерактивная браузерная проверка не проводилась.
