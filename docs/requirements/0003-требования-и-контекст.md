## Требование и границы

Хранить требования и краткий актуальный контекст рядом с кодом. Под AI-first
для этого проекта понимается порядок «запрос → записанное требование и критерии
→ выполнение → проверка → обновление контекста», описанный в `AGENTS.md`.
Отдельный внешний стандарт пользователем не указан.

## Критерии приёмки

- Текущее поведение, запуск в venv и смена порта описаны в отдельных Markdown-файлах.
- Есть реестр со стабильными ID, статусами и ссылками, а также шаблон нового требования.
- `AGENTS.md` предписывает фиксировать каждый следующий запрос до выполнения
  и обновлять результаты после выполнения.
- Краткий контекст содержит карту проекта, запуск, решения, ограничения и следующую задачу.
- Все содержательные описания ведутся на русском; подробности доступны по ссылкам
  без обязательного чтения всей истории.
