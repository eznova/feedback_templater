# REQ-0020 — Проверка сборки Docker-образа

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «проверь сборку образа, что она корректно проходит».
- Связи: REQ-0001, REQ-0002, REQ-0014, REQ-0018.

## Требование и границы

Выполнить реальную сборку текущего Dockerfile и проверить запуск приложения
и генерацию PDF внутри собранного образа. Проверить наличие встроенных шрифтов
и отсутствие локальной базы, ключа сессий и venv в образе.
При необходимости исправить состав контекста сборки. Для проверки использовать
отдельный тег `feedback_templater:build-check`, не заменяя работающий сервер.

## Критерии приёмки

- `docker build -t feedback_templater:build-check .` завершается успешно.
- Приложение запускается из образа, главная страница отвечает 200.
- Генерация выбранного раздела отдаёт PDF, Inter доступен внутри образа.
- В образе отсутствуют локальные данные и секреты каталога instance.

## Результат и проверка

Добавлен `.dockerignore`: из контекста исключены `.venv`, `.git`, `instance`,
файлы окружения, журналы, сборки и кэши. Исходный Dockerfile не потребовал изменений.
Выполнена реальная сборка `docker build -t feedback_templater:build-check .`:
успешно, контекст 1,03 МБ, зависимости установлены на `python:3.12-slim`.

Собранный образ проверен через `docker run --rm -i --network none` без bind mount
и публикации портов. Внутри запущен `python app.py`: GET / и /admin/login — 200,
POST /raci_generate — PDF 200 с одной выбранной страницей и встроенным Inter,
POST /ft_generate — HTML 200 с ожидаемым ФИО. Цвет по умолчанию — #DBD2FF.
До запуска подтверждено отсутствие `.venv`, `.git`, `.env`, `.flaskenv`, `instance`;
после запуска SQLite создана заново с 12 текстами и без администраторов.

Первый проверочный запрос с тайм-аутом 1 с не дождался ответа; повторная проверка
с ожиданием готовности сервера прошла. Рабочий сервер в venv и его база не менялись.
Проверочный контейнер автоматически удалён, образ `feedback_templater:build-check`
оставлен локально. Полный запуск через Compose с внешней сетью moc не проверялся.
