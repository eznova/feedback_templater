# REQ-0018 — Общий цвет чекбоксов и PDF

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: чекбоксы должны совпадать с сиреневым фоном PDF; цвет вынести
  в переменную с переопределением через env в Compose; без env — значение из кода.
- Связи: REQ-0017, оформление PDF из REQ-0008.

## Требование и границы

Значение по умолчанию уточнено REQ-0019: `#DBD2FF` вместо `#DDD3FF`.

Единая настройка `RACI_ACCENT_COLOR` для отмеченных чекбоксов разделов,
сиреневых блоков и плашки адресата PDF. По умолчанию `#DDD3FF` в коде.
Compose передаёт переменную только при её наличии во внешнем окружении;
значение по умолчанию в Compose не дублируется.
Формат переопределения — `#RRGGBB`; отсутствующее или пустое значение использует
цвет из кода. Некорректный цвет вызывает понятную ошибку при запуске.
Для применения изменения требуется перезапуск процесса/пересоздание контейнера.

## Критерии приёмки

- Без env чекбоксы и PDF используют `#DDD3FF`.
- С корректной env оба используют одинаковый новый цвет.
- Compose не задаёт собственное значение по умолчанию.
- Изменение оформления не меняет включение разделов и переносы PDF.

## Результат и проверка

Добавлен `settings.py`: общая настройка из env, валидация `#RRGGBB` и значение
из кода при отсутствующей/пустой переменной. PDF использует `ACCENT`, шаблон —
CSS-переменную `--raci-accent-color`. Стиль отмеченных чекбоксов и их границы
использует этот цвет. Compose содержит только проброс `RACI_ACCENT_COLOR` без
значения по умолчанию. README содержит пример настройки и применения.

Проверены отсутствующая/пустая env, корректное переопределение и отклонение
некорректных значений; в отдельных процессах подтверждено совпадение CSS и цвета PDF.
`docker compose config` проходит без env и с переопределением.
Девять тестов PDF и четыре панели прошли; `git diff --check` прошёл.
Браузерная визуальная проверка не проводилась.
