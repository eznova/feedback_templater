# REQ-0004 — Настройка .gitignore

- Дата: 2026-10-22 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «настрой .gitignore».
- Связи: REQ-0001 (venv), REQ-0003 (документирование).

## Требование и границы

Настроить исключения Git для Python/Flask-проекта: виртуальные окружения,
байткод, кэши проверок, сборки PyInstaller, журналы, локальные настройки
и файлы окружения. Сохранить существующее исключение `app.spec`.
Примеры конфигурации `.env.example` и `.env.sample` оставить доступными для Git.
Не исключать код, шаблоны, зависимости и Markdown-документацию.

## Критерии приёмки

- `.venv/` и `__pycache__/` не отображаются как неотслеживаемые файлы.
- Типовые временные файлы и локальные `.env` распознаются как игнорируемые.
- Исходники, документация и примеры конфигурации не игнорируются.
- Проверка `git diff --check` проходит.

## Результат и проверка

Обновлён `.gitignore`: добавлены исключения окружений, байткода, сборок,
кэшей, покрытия, локальной конфигурации, журналов, редакторов и файлов ОС.
Сохранён `app.spec`, разрешены `.env.example` и `.env.sample`.
Через `git check-ignore --no-index` проверены 29 игнорируемых путей
и 10 доступных для Git файлов — все ожидания выполнены.
`git status --short` больше не показывает `.venv/` и `__pycache__/`;
код и документация доступны для отслеживания. `git diff --check` прошёл.
