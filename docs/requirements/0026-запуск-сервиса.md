# REQ-0026 — Запуск Docker-сервиса

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «запусти сервис» после добавления скрипта сборки и запуска.
- Связи: REQ-0025.

## Требование и границы

Запустить Docker-сервис скриптом scripts/build-and-run.sh, проверить состояние
контейнера, доступность приложения и подключение существующей SQLite.
Использовать текущую конфигурацию Compose и сохранить данные.

## Критерии приёмки

- Скрипт успешно собирает образ и запускает контейнер feedback_templater.
- Приложение отвечает HTTP 200, подключена прежняя БД на хосте.

## Результат и проверка

Успешно выполнен scripts/build-and-run.sh: собран feedback_templater:latest,
создана отсутствовавшая сеть moc, контейнер feedback_templater запущен и имеет статус Up.
Изнутри контейнера GET http://127.0.0.1:18500/ вернул 200.
Проверена текущая SQLite: схема 1, ревизия 1, 12 текстов, существующий
администратор и две резервные копии. docker inspect подтвердил bind mount
/root/moc/feedback_templater/instance → /app/instance и сеть moc.

Контейнер получил адрес 172.18.0.2, внутри сети сервис доступен как
feedback_templater:18500. Порты на хост не опубликованы согласно текущему Compose.
Ранее запущенный сервер в venv оставлен работающим; данные не изменялись.
