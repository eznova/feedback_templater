# REQ-0001 — Запуск проекта на этой машине в venv

- Дата: 2026-10-22 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «запусти проект на этой машине (в venv)».
- Связи: REQ-0002 уточняет порт.

## Требование и границы

Создать локальное виртуальное окружение Python, установить зависимости
из `requirements.txt` и запустить приложение на текущей машине.

## Критерии приёмки

- Окружение находится в `.venv/` внутри проекта.
- Зависимости установлены, сервер использует интерпретатор этого окружения.
- Главная страница запущенного приложения отвечает HTTP 200.

## Результат и проверка

Создано `.venv` на Python 3.12.3; установлены Flask, PyInstaller и их зависимости.
Сервер запущен через `.venv/bin/python -m flask`, без отладки, на `0.0.0.0`.
Первоначальный запуск на 5000 проверен HTTP-запросом: 200; затем порт изменён
по REQ-0002. Автозапуск после перезагрузки не настраивался.
