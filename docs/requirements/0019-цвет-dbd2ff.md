# REQ-0019 — Цвет по умолчанию #DBD2FF

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «исправь цвет на DBD2FF».
- Связи: заменяет значение по умолчанию из REQ-0018.

## Требование и границы

Использовать `#DBD2FF` как общий цвет чекбоксов, цветных блоков и плашки PDF.
Сохранить переопределение через `RACI_ACCENT_COLOR` в Compose.

## Критерии приёмки

- Без env HTML/CSS и PDF используют `#DBD2FF`.
- Корректная env продолжает переопределять цвет.

## Результат и проверка

В `settings.py` цвет по умолчанию заменён на `#DBD2FF`.

и с переопределением `#abc123`. Compose с переопределением корректно проходит
`docker compose config`. README обновлён, `git diff --check` прошёл.
