# REQ-0012 — Тексты по умолчанию со скриншотов

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «Заполни текст по умолчанию. Со скриншотов нужно взять вводные
  разделы и текст целевой картины»; три приложенных скриншота.
- Связи: REQ-0006, REQ-0007. Заменяет исходное значение «Пример текста».

## Требование и границы

На всех скриншотах в двух вводных разделах и пяти блоках целевой картины
повторяется следующий текст. Заполнить им семь соответствующих начальных значений
в текущей SQLite и значения для новой базы. Пять полей «Как было» не изменять.
Сохранить возможность последующего редактирования через администратора;
повторный запуск не должен перезаписывать сохранённые значения.
Переносы строк со скриншотов являются переносами вёрстки, текст хранить одним абзацем.

## Текст со скриншотов

Повседневная практика показывает, что начало повседневной работы по формированию позиции представляет собой интересный эксперимент проверки направлений прогрессивного развития. Задача организации, в особенности же рамки и место обучения кадров влечет за собой процесс внедрения и модернизации системы обучения кадров, соответствует насущным потребностям.

## Критерии приёмки

- Два вводных поля и пять полей `*-target` содержат указанный текст в SQLite и форме.
- Поля `*-before` и учётная запись администратора не изменены.
- Новая база получает те же значения; существующие тексты при запуске не затираются.
- PDF из актуальных значений генерируется и содержит шесть страниц.

## Результат и проверка

В `admin.py` добавлен `DEFAULT_RACI_TEXT`, он используется для семи полей при
создании новой базы. В текущей SQLite одной транзакцией обновлены только эти семь
значений. Перед изменением создана копия
`instance/backups/before-REQ-0012-20261023-000544-642048.sqlite3`.
Сравнением до/после подтверждено: остальные поля и учётная запись не изменены.

Проверены точные значения семи textarea в HTML, новые значения на временной базе
и сохранность администраторской правки при повторной инициализации.
Из актуальных полей сгенерирован `/tmp/raci-default-texts.pdf`: шесть страниц,
семь вхождений абзаца подтверждены извлечением текста через Poppler.
`git diff --check` прошёл.
