# REQ-0014 — Шрифт Inter

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «шрифт должен быть Inter».
- Связи: заменяет шрифты Liberation Sans в PDF из REQ-0008; сохраняет переносы REQ-0013.

## Требование и границы

Использовать настоящий Inter Regular и Inter Bold во всех текстах PDF RACI:
заголовках, плашке адресата, подписях блоков и основном тексте.
Включить файлы и лицензию в проект, встроить шрифты в PDF для независимости
от установленных у получателя шрифтов. Размеры и цвета сохранить;
переносы рассчитывать с учётом новых метрик.

## Критерии приёмки

- PDF содержит встроенные Inter Regular и Bold и поддерживает кириллицу.
- Короткие документы по-прежнему содержат шесть страниц.
- Длинные тексты переносятся полностью и не выходят за поля страницы.

## Результат и проверка

Из официального релиза https://github.com/rsms/inter/releases/tag/v4.1 получены
Inter Regular и Bold (статические TTF), добавлены в `assets/fonts/` с лицензией
`Inter-LICENSE.txt` (SIL OFL 1.1). Неиспользуемые Liberation Sans удалены.
В `raci_pdf.py` шрифты заменены для абзацев, заголовков и плашки, а также
для вычисления её ширины. README обновлён.

Все десять тестов панели и PDF прошли. Тест PDF проверяет имена Inter-Regular
и Inter-Bold и встроенные TTF; повторно проверены переносы с 700 уникальными
строками для четырёх типов полей, кириллица, шесть страниц короткого документа
и границы текста. `pdffonts` подтвердил встраивание обоих начертаний.
PDF `/tmp/raci-inter.pdf` сформирован HTTP-обработчиком (200), вторая страница
визуально проверена через Poppler. `git diff --check` прошёл.
