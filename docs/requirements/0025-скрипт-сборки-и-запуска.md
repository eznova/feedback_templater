# REQ-0025 — Скрипт сборки и запуска Docker

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: «добавь скрипт сборки и запуска в scripts/».
- Связи: REQ-0020, REQ-0021, REQ-0023.

## Требование и границы

Добавить исполняемый Bash-скрипт `scripts/build-and-run.sh`, запускаемый из
любого рабочего каталога. Проверить наличие Docker, Compose и доступ к daemon,
проверить Compose-конфигурацию, собрать образ `feedback_templater`, обеспечить
наличие сети `moc` и каталога instance/, запустить сервис в фоне с пересозданием.
При ошибке сборки не запускать/не пересоздавать контейнер. Существующие данные сохранять.
Поддержать --help. Новые порты и настройки в Compose не добавлять.

## Критерии приёмки

- Скрипт имеет права исполнения, Bash-синтаксис корректен.
- Запуск из другого каталога собирает проект из правильного корня.
- Неуспешная сборка останавливает выполнение до Compose up.
- Существующая сеть не пересоздаётся, отсутствующая создаётся после успешной сборки.
- Команда запуска и поведение описаны в README.

## Результат и проверка

Добавлен исполняемый `scripts/build-and-run.sh`: Bash strict mode, переход в корень
от местоположения скрипта, проверки Docker/Compose/daemon и конфигурации, сборка
тега feedback_templater, создание отсутствующей сети moc, запуск Compose с
--detach --force-recreate. Каталог instance создаётся с umask 077, старые данные
не удаляются. Добавлены --help, сообщения об ошибках и инструкция в README.

Пройдены bash -n, --help, docker compose config --quiet и git diff --check.
С имитацией Docker проверены пять сценариев: существующая/отсутствующая сеть,
ошибка сборки, daemon и конфигурации. Проверены запуск из другого каталога
и путь с пробелами; ошибка сборки сохраняет код 17 и не вызывает Compose up
или создание сети. Неизвестный аргумент отклоняется с кодом 2.
Реальный сервис этим скриптом в рамках задачи не пересоздавался.
