# REQ-0028 — HTML-отчёт RACI

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: добавить в форму RACI основную кнопку «Сгенерировать отчет», которая выводит документ на странице в формате отчёта встреч.
- Связи: REQ-0000, REQ-0008, REQ-0017, REQ-0018.

## Требование и границы

Добавить HTML-отчёт RACI с оформлением страницы отчёта встреч: табличная вёрстка,
белый документ на сером фоне, округлённая рамка заголовка, шрифт Inter.
Предположение: существующее скачивание PDF остаётся второй кнопкой.
Отчёт учитывает введённые тексты, подразделение, адресата и выбор разделов.

## Критерии приёмки

- Основная кнопка «Сгенерировать отчет» открывает HTML-документ на странице.
- Вторая кнопка «Сгенерировать PDF» по-прежнему скачивает PDF.
- Отключённые разделы исключены, адресат «Не отображать» скрывает плашку.
- Переносы строк сохраняются, пользовательский HTML экранируется, длинный текст не обрезается.
- Ошибка заполнения показывает сообщение с сохранением данных формы.
- Отчёты встреч продолжают работать.

## Результат и проверка

общий цвет, экранирование и переносы текста. Ошибки HTML возвращают форму с данными.
В `src/raci_pdf.py` выделена общая валидация без изменения PDF-вёрстки.
