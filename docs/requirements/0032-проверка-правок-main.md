# REQ-0032 — Проверка локальных правок хоста в main

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: Выполнено.
- Источник: проверить, есть ли в main показанные локальные изменения хоста: комментарий build, публикация 5081:5000 и локальный Bootstrap.
- Связи: REQ-0029, REQ-0030.

## Требование и границы

Обновить сведения об origin/main и сравнить конфигурацию и подключение Bootstrap
с переданным git diff. Результат — ответ и фиксация выводов; код и развёртывание
не менять. Сам хост пользователя доступен только через присланный diff.

## Критерии приёмки

- Указать проверенный коммит main и наличие каждого изменения.
- При отличиях от d/raci явно указать соответствующую ветку.

## Результат и проверка

git fetch origin завершился успешно. Проверена origin/main: 5afe779 (deploy).
В ней нет ни комментария # build: ., ни секции ports 5081:5000.
В templates/form.html Bootstrap 5.3.2 подключён с CDN jsdelivr;
локальное подключение через url_for(static, bootstrap.min.css) отсутствует.
В дереве main нет файла static/bootstrap.min.css. Git diff не показывает
неотслеживаемые файлы хоста; наличие локального CSS на хосте не установлено.

В origin/d/raci порт опубликован как 5081:18500, а Bootstrap также подключён
с CDN. Локальные правки хоста не были автоматически перенесены в ветки GitHub.
Проверка выполнена через git show, git ls-tree и сравнение веток;
код, main и развёртывание не менялись.
