# REQ-0041 — Условная сборка и автообновление systemd

- Дата: 2026-10-23 (Europe/Moscow).
- Статус: В работе.
- Источник: пересобирать и перезапускать при изменениях после git pull; запускать скрипт каждые 30 секунд через systemd. Уточнение: устанавливать сервис также из скрипта.
- Связи: REQ-0025, REQ-0036, REQ-0039.

## Требование и границы

Сравнивать HEAD до/после git pull --ff-only. Без новых коммитов сборка и
перезапуск пропускаются. Незавершённое обновление повторять после ошибки;
--force сохраняет ручную сборку/первоначальный запуск без новых коммитов.
Сохранить самообновление скрипта и проверку версии контейнера.
Защитить Git/сборку блокировкой от одновременных запусков.

В том же scripts/build-and-run.sh добавить --install-systemd: установить
пользовательские service/timer для фактического каталога проекта, выполнить
daemon-reload и enable --now. Таймер запускает скрипт через 30 секунд после
завершения предыдущего запуска (долгие сборки не перекрываются).
Предположение: автозапуск требуется на хосте пользователя; на данной машине
установка проверяется без изменения его хоста. Для работы после выхода
из сессии требуется systemd linger, команда указывается в инструкции.

## Критерии приёмки

- Без изменений после pull Docker не вызывается.
- При новых коммитах или --force выполняются сборка и перезапуск.
- После ошибки сборки/проверки следующая проверка повторяет обновление.
- Самообновление не теряет факт новых коммитов; параллельный запуск пропускается.
- --install-systemd устанавливает и включает service/timer для текущего пути.
- Установка проверяет systemd user manager до записи; --help не изменяет систему.

## Результат и проверка

В скрипте добавлены сравнение HEAD, --force, --install-systemd,
flock-блокировка и pending-маркер в служебном каталоге Git. Маркер удаляется
только после успешного запуска и проверки версии; самообновление сохраняет
маркер и блокировку. Добавлены scripts/systemd/*.service и *.timer.
Установщик проверяет пользовательский менеджер systemd, копирует units,
создаёт drop-in с реальным путём проекта (экранирует пробелы/проценты),
выполняет daemon-reload и enable --now. README содержит команды linger,
просмотра журналов и отключения таймера.

11 тестов tests.test_start_script прошли: отсутствие изменений, обновление,
force, повтор сборки/проверки после ошибки, отказ pull, самообновление,
конкурирующая блокировка, установка units, недоступный systemd и help.
bash -n и systemd-analyze verify прошли. Реальный обычный запуск после pull
вывел «Новых коммитов нет» и не вызывал сборку/перезапуск.
PID 1 текущей среды — codex, systemd-таймер здесь не активировали;
установка проверена в изолированном каталоге с подменой systemctl.
Реальная --force проверка и публикация выполняются после коммита.
